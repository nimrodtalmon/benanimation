# Drawing kit for Ben

The animation is a puppet: each moving part is its own drawing, and the code moves
them to the music. To swap my code drawings for yours, draw each part on its own
page (plain white paper, closed black outlines, marker colors as usual).

## One character = these pages
1. Head without face features (front view): hair, ears, face shape.
2. Eyes: open, half closed, closed (both eyes on one page, three times).
3. Mouths, 6 shapes (the classic cartoon set, used by lip-sync tools):
   - A: closed (M, B, P)
   - B: slightly open, teeth together (most consonants)
   - C: open (EH, AE)
   - D: wide open (AA)
   - E: rounded (AO, ER)
   - F: puckered (OO, W)
4. Torso with clothes, no arms (front view).
5. Upper arm, forearm, hand x2 (one open, one gripping).
6. Upper leg, lower leg, shoe.
7. Instrument (guitar / drum kit pieces / mic), if the character plays one.

Draw the joints a bit longer than needed (round ends), so they overlap when they bend.
A side view (same pages, from the side) can come later.
